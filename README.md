## 一、目录地图

| 目录 | 装什么 | 冻结性质 |
|---|---|---|
| `00-流程/` | **怎么做事**的流程与判据（元层，最高约束） | 改动需用户裁决 |

| `60-决策记录/` | 每条决策的留档 | **只追加不改写** |

| `80-资料/` | **素材**，不分"区"，只挂采用状态 | 否 |

> **本结构与旧结构的根本区别**：文件按**生命周期状态**分，不按话题分。
> 旧结构（`../newproject2/设计/待确定.md`）一个文件塞 500 行，内部混了「已裁决 / 待裁决 / 已否决」三种状态 ⇒ 不可定位、不可检索。本结构把三种状态切成三个目录。
