# 80-资料/

> **一句话**：装**素材**；这里**没有"确认区 / 待定区"之分**，只挂**采用状态**。
> **理由**：资料本身是否被核实，属于素材属性，**不是设计决策**；混用"确认区 / 待定区"会造成边界错乱 —— 这是 2026-09-18 已踩过的坑，本结构延续该修正。
> **谁能写**：AI 可写；**采用状态的改动权在用户**。

---

## 采用状态（四种，沿用既有约定）

| 符号 | 状态 | 含义 |
|---|---|---|
| ⏳ | 待采用 | **默认状态** |
| ✅ | 已采用 | 已用于某层设计（须注明用在哪个条目） |
| ❌ | 不采用 | 明确不用，须写理由 |
| 🔁 | 待重搜 | 取证不足，需要补充来源 |

---

## 每条资料的必备字段

| 字段 | 说明 |
|---|---|
| 一句话内容 | ≤ 一行 |
| 来源 | 出处（文件路径 / URL / 用户原话） |
| 可信度 | 实测 / 官方文档 / 厂商公开 / 推测 |
| 采用状态 | ⏳ / ✅ / ❌ / 🔁 |
| 用在哪个条目 | 采用时必须回指到具体的 ID（如 `REQ-xxx`） |
