## 方向 1 · 数字孪生的分层定义

工业界与学界对"数字孪生"存在多套分层口径，核心分歧在于"虚实之间是否实时同步、能否反向控制、能否预测与自主优化"。下列为权威来源的分层定义。

| 结论 | 来源（URL 或可追溯出处） | 可信度 |
|---|---|---|
| 数字孪生最早由 Michael Grieves 于 2002–2003 年提出三维模型：物理实体、虚拟模型、二者之间的连接；NASA 给出首个实用定义——"对建成资产的集成多物理场、多尺度、概率性仿真，镜像其全生命周期"。 | Grieves / NASA (Glaessgen & Stargel, 2012)；ScienceDirect 综述 https://www.sciencedirect.com/science/article/pii/s3050483x26000158 | 官方文档（学术综述） |
| ISO 23247《制造用数字孪生框架》将数字孪生定义为"针对可观测制造要素（OME）的、与其实体保持同步的、fit-for-purpose 数字化表达"，并列出 8 类 OME（人员、设备、物料、过程、设施、环境、产品、支撑文档）。 | ISO 23247-1:2021 官方标准 https://www.iso.org/obp/ui/fr/?_escaped_fragment_=iso%3Astd%3A78744%3Aen | 官方文档（ISO 标准） |
| 陶飞团队在 Grieves 三维模型基础上提出**数字孪生五维模型** MDT=(PE, VE, Ss, DD, CN)，新增"孪生数据(DD)"与"服务(Ss)"两个维度，强调全要素、全流程、全生命周期映射。 | 陶飞等，《数字孪生五维模型及十大领域应用》，《计算机集成制造系统》；https://pmt.ustb.edu.cn/article/id/fee91e56-3116-4803-9da6-4a3e6d26fb46 | 官方文档（学术论文） |
| 陶飞团队提出**数字孪生成熟度模型（六级）**：L0 以虚仿实、L1 以虚映实、L2 以虚控实、L3 以虚预实、L4 以虚优实、L5 虚实共生，以"连接交互方式与自动化程度"为主线划分。 | 陶飞等，《数字孪生成熟度模型》，《计算机集成制造系统》2022,28(5):1267-1281；中国测绘学会转载 https://www.csgpc.org/detail/21727.html | 官方文档（学术论文） |
| 国标 **GB/T 46237-2025《信息技术·数字孪生能力成熟度模型》**（2025 发布，2026 实施）明确 5 个递进等级：虚拟建模、虚实映射、双向交互、智能决策、自主演化，与陶飞模型基本一致。 | GB/T 46237-2025（全国信标委）；PlusStd 标准页 https://plusstd.com/standard/1075882096/gb-t-46237-2025 | 官方文档（国家标准） |
| ISO 23247 框架将系统划分为四大域：可观测制造域、数据采集与设备控制域、核心域（计算/分析/仿真）、用户域，强调跨域双向数据交换与同步。 | ISO 23247-2 参考架构；NIST 论文 https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=936543 | 官方文档（ISO 标准） |
| 学界以"数字模型(Digital Model)→数字影子(Digital Shadow)→数字孪生(Digital Twin)"区分层级：数字模型离线、数字影子单向自动同步、数字孪生实现**双向闭环**交互（可反向驱动物理实体）。 | Datta et al. (2026) 综述；Emergent Mind https://www.emergentmind.com/topics/digital-twins-and-simulation-in-the-loop | 官方文档（学术综述） |
| 业界通行的能力分层（按价值递进）：描述性（发生了什么）、诊断性（为什么发生）、预测性（将会发生什么）、规范性（该怎么做），层级越高对模型与数据要求越高。 | Verdantis《Digital Twin Meaning in Maintenance》https://www.verdantis.com/?p=43698/ | 厂商公开 |
| 另一种五层成熟度口径：Level 1 状态（静态副本，无实时数据流）、Level 2 信息（单向实时监控）、Level 3 预测（AI/ML 预测未来）、Level 4 优化（双向控制与优化）、Level 5 自主（自修复、自优化）。 | MDPI 综述《AI-Driven Digital Twins in Industrialized Offsite Construction》https://www.mdpi.com/2075-5309/15/17/2997/xml | 官方文档（学术综述） |
| 数字孪生基础设施可被拆为分层栈：物理层（传感器/SCADA/PLC）→连接层（网络/网关）→数据处理层（云/边）→建模层（仿真/行为模型）→集成层（CMMS/ERP 等），任一层是短板则整体受限。 | Verdantis https://www.verdantis.com/?p=43698/ | 厂商公开 |
| 共识性边界：仅做"3D 模型 + 离线仿真"而**无实时数据同步**的系统，按多数标准不被视为真正数字孪生，最多算数字模型或数字影子。 | ISO 23247 定义 + 陶飞成熟度 L0 界定综合；https://www.csgpc.org/detail/21727.html | 推测（由标准定义逻辑推断） |

## 方向 4 · 虚拟下位机 / 设备仿真器在数字孪生项目中的通行做法

没有真实硬件时，被控对象怎么模拟、有哪些成熟做法、模拟到什么粒度算常见。

| 结论 | 来源（URL 或可追溯出处） | 可信度 |
|---|---|---|
| 虚拟调试（Virtual Commissioning）通行三阶段递进：模型在环 MiL（逻辑模型连仿真模型）→ 软件在环 SiL（编译后代码跑在 PLC 仿真器上）→ 硬件在环 HiL（真实控制器连虚拟被控对象），逐级验证。 | Virtual Commissioning 指南 https://virtualcommissioning.com/hybrid-digital-twin-for-virtual-commissioning | 厂商公开 |
| **虚拟 PLC（vPLC / soft PLC）**是通行做法：用软件模拟物理 PLC 行为，无需硬件即可编写、测试、调试控制逻辑，是虚拟调试的核心组件。 | 百度百科《PLC仿真软件》https://baike.baidu.com/item/PLC仿真软件/9326502 ；工控网《虚拟PLC迈向实用化》https://m.gkong.com/News/109644.html | 厂商公开 |
| 西门子通行方案：PLCSIM Advanced 创建虚拟 PLC（精准模拟 S7-1500），与 NX MCD（3D 机械与运动仿真）、SIMIT（过程/传感器执行器仿真）联动，构成完整数字孪生方案。 | MEG 朗库《西门子PLC在数字孪生中的应用》https://megilang.com/Industry-News/Application-Technology-Analysis-Scheme-of-Siemens-PLC-in-Digital-Twins-in-Industrial-40-Era.html | 厂商公开 |
| 在数字孪生/HIL 测试中，被控对象以"高保真、可实时执行的虚拟模型（plant model）"呈现，作为嵌入式控制器的验证环境，形成闭环测试。 | Inference Systems《Digital Twin / HIL》https://inferensys.com/glossary/sim-to-real-transfer-learning/hardware-in-the-loop-testing/digital-twin | 厂商公开 |
| HIL 对实时性有硬约束：数字孪生须在确定性、亚毫秒时间步内执行，否则无法验证控制稳定性与瞬态响应；实时性不足则孪生对控制验证无意义。 | Inference Systems（同上） | 厂商公开 |
| 仿真保真度采用分级策略以平衡算力：高保真（非线性、接触、高带宽动力学，用于最终验证）、中保真（线性化，用于功能测试）、低保真（运动学，用于早期算法）——可同一测试中切换。 | Inference Systems（同上） | 厂商公开 |
| 信号映射与 I/O 仿真是关键环节：虚拟 PLC 的 I/O 须与 3D 模型精准对应；传感器仿真（编码器/限位/视觉，含噪声与延迟）与执行器模型（响应曲线/饱和/故障）须还原真实世界特性。 | Inference Systems《Virtual Commissioning》https://inferensys.com/glossary/sim-to-real-transfer-learning/digital-twin-creation/virtual-commissioning | 厂商公开 |
| **故障注入（fault injection）**是虚拟仿真的突出价值：可安全模拟传感器偏置/丢失、执行器饱和、断电等极端工况，验证安全机制与控制器鲁棒性，物理上难复现。 | Inference Systems（同上） | 厂商公开 |
| CNC 领域的轻量切入点：将 NC 程序 + 机床模型 + 夹具 + 毛坯导入 VERICUT 跑一遍，提前抓碰撞/超程/过切/刀具干涉，被称为 ROI 最硬的虚拟调试起点（避免一次撞机维修费 5 万起 vs 软件年费约 2 万）。 | 数控大师《CNC车间数字孪生轻量版切入点》（微信搜一搜转载） | 厂商公开（行业分析/案例） |
| 虚拟调试业务收益实证：含 6 台机器人 12 工位的智能线，纯现场调试平均约 45 天；数字孪生前置调试可压缩周期 60%+，并将"现场调参"前置为"数据驱动优化"。 | 特瑞杰智能《基于数字孪生的智能生产线虚拟调试流程》http://www.topregen88.com/product/50006.html | 厂商公开（落地案例） |
