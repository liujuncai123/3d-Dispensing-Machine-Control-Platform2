# 二、剩余 4 个槽位（请裁）

## ⏳ §2 · 数字孪生深度 —— **措辞必须先改，否则面试会踩坑**

> **一句话**：我们内部的 L3 和行业口径的 L3 **不是一回事**，必须换一套不撞车的说法。

| | **我们的能力层（内部用）** | **行业成熟度（对外说）** |
|---|---|---|
| T1 | 3D 模型 + 实时状态映射 | **L1 以虚映实** |
| T2 | + 轨迹编程 / 预览 / 校验、下发可控 | **L2 以虚控实** |
| T3 | + 虚拟下位机造误差 → 上报 → 归正 | ⚠️ **不是行业 L3**（行业 L3 = 预测与优化） |

**⚠️ 风险**：行业口径的 L3+ 需要**真实传感数据**（功率 / 力 / 振动 / 磨损），而我们是虚拟下位机，**拿不到**（依据 `../80-资料/01-...md` 方向 4）。若你对外说"做到 L3"，会被理解成预测性维护 ⇒ 答辩翻车。

**好消息**：行业对"及格线"的定义是「必须有**实时双向数据同步**，否则只是 3D 看板」——我们的 T1+T2 **已达标**。

| 选项 | 范围 | 客观代价 |
|---|---|---|
| **A** 只到 T2 | 实时同步 + 可控，**不做**误差模拟 | 最小；但**闭环断在"误差→归正"这一段**（违反你刚说的"简单模拟是闭环必需"） |
| **B** T1+T2+T3（简化版） | 加"误差产生 → 上报 → 线性归正" | 多一个小闭环；**有算法可讲**（不只是界面） |
| **C** 再往上加预测 | 需真实数据 | **不可行**（虚拟下位机拿不到物理量） |

- **倾向**：**B**；对外表述固定为「**实时双向同步的 3D 可视化 + 远程可控 + 虚拟下位机闭环**」，**不宣称行业 L3**

## ⏳ §3 · 设备台数

> **一句话**：资料把这个问题的答案坐实了 —— **多设备正是差异化所在**。

依据 `../80-资料/03-...md` 方向 5：7 类商业点胶软件（Nordson Fluidmove / EasyCoat / UnityMotion / UltimusPlus、武藏 MuCADV、旗众智能、众为兴）**全部是单机形态**，多设备靠上层 MES/SCADA，**3D 孪生均非标品**。

| 选项 | 代价 |
|---|---|
| **A 单台** | 最省；但**丢掉最大的差异化点** |
| **B 多台** | 需设备列表 / 状态汇聚 / 批量下发 / 并发；但**市面上几乎空缺** |

- **倾向**：**B 多台**（简化：只做列表 + 状态汇总 + 逐台/批量下发，**不做** MES 对接）

## ⏳ §4 · 项目定位

| 选项 | 代价 |
|---|---|
| **A 主力项目** | 投入最大、文档与测试最全；简历第一项目 |
| **B 次要项目** | 投入小；但与"从零重建整套流程"不匹配 |

- **倾向**：**A 主力项目**（你已为它重建了整套流程与结构，事实上的定位）

## ⏳ §6 · 完成判据

| 选项 | 代价 |
|---|---|
| 只"可演示" | 最快；但面试经不起深挖 |
| 可演示 + 可讲清 | 中等 |
| **可演示 + 可讲清 + 单元测试** | 需为核心模块写单测（**只需核心**：轨迹、校验、虚拟下位机时序、归正、存储） |

- **倾向**：**三项全纳**（单测只覆盖核心算法与接口，不追求高覆盖率）

## 3.2 预留（**有接口、无实现**）—— 对应"一个人做不完"

| 项 | 预留形式 |
|---|---|
| 物理仿真（功率 / 力 / 振动 / 磨损） | `IErrorSource` —— 误差模型可替换 |
| 预测性维护 | 数据结构不假设"无预测" |
| 真实 CCD 视觉（Mark 提取 / 九点标定 / 手眼标定 / AOI / 飞拍） | `IVisionProvider` —— 当前用模拟实现 |
| 真实补偿算法（PID / 模型参考自适应） | `ICorrectionStrategy` —— 当前线性 |
| DXF / G 代码 / PLT 导入 | `ITrajectoryImporter` —— 当前不实现 |
| OPC UA / SECS/GEM | 通信层抽象 |
| 配方库 / 版本 / 审计 | 工艺参数独立成模块 |
| MES / ERP 对接 | 下发层抽象 |

## 3.3 不做（明确排除）

| 项 | 理由 |
|---|---|
| 基于物理量的寿命 / 磨损预测 | 需真实传感数据，虚拟下位机拿不到（01-方向4） |
| 五轴 / 旋转轴 | B-001 已定 3 轴直线 |
| 真实硬件对接 | 无硬件（虚拟下位机替代） |
| 权限 / 主题 / 多语言 / 自定义布局 | 超出单人范围 |
| 多平台（Linux / macOS）/ 安装包制作 | 超出单人范围 |
