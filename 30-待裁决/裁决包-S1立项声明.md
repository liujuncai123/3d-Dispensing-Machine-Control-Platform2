# 二、本轮待裁（≤3 条）

## ⏳ B-001 · 机构形态与轴的定义

> **一句话**：这台机器长什么样、3 个轴各是什么运动 —— 它决定 3D 场景的建模对象和运动学复杂度。

### 子问题 1 · 机构形态

| 选项 | 说明 | 客观代价 |
|---|---|---|
| **A 龙门式** | 双立柱 + 横梁，Z 轴挂在横梁的 X 轴滑座上 | 视觉上最像"工业点胶机"；图元拼需要 4–6 个长方体组合；运动学仍是 3 轴直角坐标（**不含**双驱同步/跨度补偿） |
| **B 悬臂 / 单柱式** | 单立柱 + 悬臂 | 图元更少；但行业辨识度低于龙门 |
| **C 桌面型小型平台** | 小型三轴点胶平台 | 图元最少；但"数字孪生 + 工业软件"的观感弱 |
| **D 抽象几何** | 不建模具体机架，只表现 XYZ 三轴运动关系 | 图元最省、最省事；但**失去"像真机器"的演示效果**（而"可演示"是你的完成判据之一） |

**与 B-008 的关系**：B-008 已定**图元拼** ⇒ A（龙门）用 4–6 个长方体即可拼出，**成本可控**；D 最省但演示效果最弱。

### 子问题 2 · "3 轴"的定义

| 选项 | 说明 | 代价 |
|---|---|---|
| **X / Y / Z 三轴直线**（无旋转轴） | 直角坐标直线运动 | 运动学最简单；符合"3 轴"字面 |
| 含 1 个旋转轴（如胶枪旋转 / 工件旋转） | — | 需四轴插补与旋转变换，**复杂度显著上升**；且与"3 轴"字面冲突 |

- **未定默认**：子问题 1 = **A 龙门式**（行业辨识度 + 图元拼可承受）；子问题 2 = **XYZ 三轴直线**
- ⚠️ 子问题 1 的默认值**仅为不停摆** —— 因为你这次根本没提龙门，**强烈建议你明确一次**

## ⏳ B-002 · 数字孪生的深度

> **一句话**："孪生"做到哪一层 —— 这是决定整个项目规模的最大的单选。

| 层 | 内容 | 累加后是什么 |
|---|---|---|
| **L1 可视化层** | 3D 模型 + **实时状态映射**（轴位置 / 运行状态 / 告警） | 会"动"的 3D 看板 |
| **L2 规划层** | + **轨迹编程 / 预览 / 程序检查** | 能在 3D 里编程序、能校验 |
| **L3 误差模拟** | + 虚拟下位机**造误差并上报** → 上位机**归正** | 有算法闭环，**不只是界面** |
| **L4 物理仿真** | 流体 / 固化过程 | 需要真实物理建模，通常排除 |

### 选项（做到哪一层为止）

| 选项 | 范围 | 客观代价 |
|---|---|---|
| **A 止于 L1** | 只有 3D 状态映射 | 最小；但**没有"规划"能力**，选题里"数字孪生"的含金量大幅缩水 |
| **B 止于 L2** | L1 + L2 | 有轨迹编程与校验；**没有算法闭环**，面试可讲的点偏"界面 + 架构" |
| **C 含 L3** | L1 + L2 + L3 | **有算法闭环**（误差 → 归正），可讲"数据流 + 策略可替换"；规模最大 |
| **D 含 L4** | 全含 | 需要流体/固化物理模型，**超出"轻量做仿真"的定位**（B-007 待裁） |

> ⚠️ **L3 有一个隐含前提**：它要求存在**虚拟下位机**（B-012 待裁）。若 B-012 裁定为"不需要"，则 L3 自动不成立。

- **未定默认**：**C（含 L3）** —— 上一轮你曾就同类问题答「要，加误差模拟」；但这属新项目，**不继承**，请重新确认

## ⏳ B-003 · 一套上位机管几台设备

> **一句话**：单台还是多台 —— 它决定是否要有设备列表、状态汇聚、并发与批量下发。

| 选项 | 说明 | 客观代价 |
|---|---|---|
| **A 单台** | 只管一台设备 | 最简单；无并发、无状态汇聚；但**少了一个差异化点** |
| **B 多台** | 一套上位机管 N 台 | 需设备列表 / 状态汇总 / 批量下发 / **并发与线程归属**；工作量增加；但**差异化明显** |
