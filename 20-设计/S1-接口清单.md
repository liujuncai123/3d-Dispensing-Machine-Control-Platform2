## 一、公共约定

### 1.1 公共类型（**无 Qt / VTK 依赖**）

> 依 `S1-#5依赖图方法-定稿.md` **§五 禁边清单**：`core/* → qt`、`core/* → vtk`、`comm/* → vtk`、`data/* → vtk` 一律禁止（"核心不暴露 Qt / VTK 头"，模块划分轮 32）。
> ⇒ **`core/*` · `comm/*` · `data/*` · `infra/*` 的接口声明用标准 C++ 类型**；**只有 `app/*` 允许用 Qt 类型**（`app/* → qt` 是合法边）。`app/replay` 与样板一致：**接口头本身保持无 Qt / VTK 依赖**。

```cpp
// 以下类型供 core/comm/data/infra 各模块接口共用；定义由 §十「字段定义归属」指定
struct Result { bool ok; ErrorCode code; std::string message; };  // 统一返回；code 取 infra 错误码表（REQ-NFR-007）
using DeviceId  = std::string;                 // 设备标识（REQ-DEV-001 口径）
using Timestamp = std::int64_t;                // 毫秒；口径待 AS-006（tMs 时基，见 §六 T-10）
struct Vec3 { double x; double y; double z; }; // 单位 mm（REQ-DB-005 单位统一）

enum class DeviceState { Offline, Ready, Running, Paused, EStop, Alarm, Homing, Purge }; // REQ-STA-001（8 态）
enum class AlarmLevel  { Info, Warning, Critical };                                       // REQ-ALM-001（三级）
```

### 1.2 命名 / 返回约定

| 项 | 约定 | 依据 |
|---|---|---|
| 接口命名 | 抽象接口一律 `I` 前缀（`I*`）；纯虚基类，**不含实现** | `P-3` / `P-4`；样板 §2.2 |
| 返回约定 | 可失败操作返回 `Result`（含 `ErrorCode`）；查询返回值 / `std::optional` | `REQ-NFR-007` |
| 单位 / 字段名 | 同一含义**不出现两种字段名**；状态取值**复用 8 态枚举** | `REQ-DB-005` ①②③ |
| 只读视图 | 只读查询**不缓存**，每次读同一份（防多视图不一致） | §五 硬约束③ |

### 1.3 与依赖边表的关系

- **出边 = 本模块作"使用者"的边**；**入边 = 本模块作"被使用者"的边**。
- 边表**原文行**在本文件中的格式**严格对齐**：`<使用者> -> <被使用者> | <A|B|D> | <类型> | <出处>`。
- **`main -> <模块>` 记入该模块的入边**（`main` 是装配点 / 组合根，非模块）。
- **`<模块> -> qt` / `<模块> -> vtk` / `<模块> -> apps/virtual-device` / `<模块> -> E*`** 均**照录**在其出边。
- 🔴 **本文件不新增、不删减任何边**：出边 / 入边**与边表逐条一一对应**；凡某模块在边表中**无出边 / 无入边**，**显式声明 + 说明原因**（见 §四）。

#### M-05 · `app/replay`　【UI 层】
**① 职责**：历史数据回放的**独立模块**（"第二事实源"，只可视化、**绝不下发**）；**数据源可替换、播放器只产出帧、呈现层在实时源与回放源间切换**。
> 🔴 **本节与 `20-设计/S1-回放-独立模块接口预留.md` 对齐（同一批接口名 / 签名），不另起一套。**

**② 对外接口**

```cpp
// ── 与样板 §2.1 / §2.2 逐字对齐 ──
// ① 数据源抽象（P-3：换实现不改调用方；覆盖"SQLite 直读"与"导入文件"两条路径）
class IReplaySource {
public:
    virtual ~IReplaySource() = default;
    virtual Result       open(const ReplaySourceDesc&) = 0;
    virtual void         close() = 0;
    virtual ReplayRange  range()   const = 0;
    virtual QStringList  devices() const = 0;
};
// ② 按时间轴取帧（缺口 G-5；亦为 app/scene3d / app/dashboard 的只读帧源）
class IReplayFrameReader {
public:
    virtual ~IReplayFrameReader() = default;
    virtual qint64                     frameCount()    const = 0;
    virtual std::optional<ReplayFrame> frameAt(qint64 i) const = 0;
    virtual qint64                     seekByTime(qint64 tAbsMs) const = 0;
};
// ③ 时钟 / 节拍（倍速；档位复用 B-024）
class IReplayClock {
public:
    virtual ~IReplayClock() = default;
    virtual void   start(qint64 tickMs) = 0;
    virtual void   stop()  = 0;
    virtual void   setSpeed(double) = 0;
    virtual double speed() const = 0;
};
// ④ 呈现侧接收（依赖倒置：app/replay 不认识 VTK/Qt 部件）
class IReplaySink {
public:
    virtual ~IReplaySink() = default;
    virtual void onFrame(const ReplayFrame&) = 0;
    virtual void onStatus(ReplayStatus)      = 0;
};
// ⑤ 播放控制（组合 ②+③，向 ④ 推帧；同时是"回放模式"的唯一状态来源）
class IReplayPlayer {
public:
    virtual ~IReplayPlayer() = default;
    virtual Result       load(std::unique_ptr<IReplaySource>) = 0;
    virtual void         play()  = 0;
    virtual void         pause() = 0;
    virtual void         stop()  = 0;
    virtual void         seek(qint64 tAbsMs) = 0;
    virtual void         setSpeed(double)    = 0;
    virtual void         step(qint64 deltaFrames) = 0;
    virtual ReplayStatus status() const = 0;   // 🔑 互斥仲裁的唯一来源（H-3）
    virtual void         attachSink(IReplaySink*) = 0;
    virtual void         detachSink(IReplaySink*) = 0;
};
```
