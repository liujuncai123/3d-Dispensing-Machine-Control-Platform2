## `REQ-NFR-002` · 多设备下响应不劣化到不可用

| 字段 | 内容 |
|---|---|
| **描述** | N 台设备同时在线时，界面应仍可操作，不出现卡死或无响应。 |
| **验收判据** | ① 在 `AS-002` 台数下，界面操作**仍有响应**（无卡死）<br>② 状态刷新**不中断**<br>③ 设备数增加时，响应时间**增长可控**（不得指数劣化） |

| **异常 / 边界** | **"不可用"的阈值未定**（建议定"任意操作响应 ≤ 2s"之类）⇒ **需你确认**；本条与 `REQ-3D-010`（精度分级）**协同**——精度分级正是为了不劣化 |
| **依赖** | `AS-002`（台数）· `REQ-3D-010` · `REQ-DEV-003` |
| **来源** | 第 3 组 `F1` 性能 |
| **优先级** | **P0** |
| **可测性** | 人工（性能观察）+ 演示 |
| **状态** | ⏳ 待裁 |
