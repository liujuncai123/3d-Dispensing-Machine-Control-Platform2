# 一、D5 · 运行控制（9 条）

## `REQ-RUN-001` · 启动 / 运行

| 字段 | 内容 |
|---|---|
| **描述** | 系统应能对指定设备下达"启动"指令，令其开始执行当前程序。 |
| **验收判据** | ① 就绪态下下达启动 ⇒ 设备进入**运行**态<br>② 运行中界面显示**当前执行到的基元序号**<br>③ 启动后 `D1` 的 3D 机构**开始随坐标移动** |
| **前置条件** | 设备状态 = **就绪**；且**已回零**；且当前程序**已通过校验** |
| **异常 / 边界** | 处于暂停态时下达启动 ⇒ 语义为**继续**（非重头开始）；程序为空或校验未过 ⇒ 拒绝并给出原因 |
| **依赖** | `REQ-RUN-006`（回零）· `REQ-CHK-*`（校验）· `REQ-STA-003`（非法迁移拒绝） |
| **来源** | `C1`（8 项之 1）· `03-资料` 方向 1「启动是必备项」 |
| **优先级** | **P0** |
| **可测性** | **单测**（状态迁移）+ **演示** |
| **状态** | ⏳ 待裁 |

## `REQ-RUN-002` · 暂停

| 字段 | 内容 |
|---|---|
| **描述** | 系统应能在运行中暂停执行，并支持随后继续。 |
| **验收判据** | ① 运行中下达暂停 ⇒ 进入**暂停**态，机构**停止移动**<br>② 暂停态保留**当前执行位置**（不回到起点）<br>③ 再次启动 ⇒ 从**暂停处继续** |
| **前置条件** | 设备状态 = 运行 |
| **异常 / 边界** | 暂停期间收到新程序 ⇒ 按 `REQ-DEV-*` 的互斥规则处理（不静默替换） |
| **依赖** | `REQ-RUN-001` · `REQ-STA-*` |
| **来源** | `C1`（2/8）· `03-资料` 方向 1「暂停是必备项，部分设备单键复用」 |
| **优先级** | **P0** |
| **可测性** | **单测** + 演示 |
| **状态** | ⏳ 待裁 |

## `REQ-RUN-003` · 停止

| 字段 | 内容 |
|---|---|
| **描述** | 系统应能停止执行，并使设备退出运行流程（**区别于暂停**）。 |
| **验收判据** | ① 运行 / 暂停中下达停止 ⇒ 退出运行，转入**就绪或待机**<br>② 停止后**不保留**执行进度（再次启动为**从头开始**）<br>③ 界面上"停止"与"暂停"**语义可区分**（不同按钮/提示） |
| **前置条件** | 运行 / 暂停 / 回零中 |
| **异常 / 边界** | 停止过程中的中间态须可见（不得界面卡住无反馈） |
| **依赖** | `REQ-RUN-002`（两者语义必须区分）· `REQ-STA-001` |
| **来源** | `C1`（3/8）· `03-资料` 方向 1 |
| **优先级** | **P0** |
| **可测性** | **单测** + 演示 |
| **状态** | ⏳ 待裁 |

## `REQ-RUN-004` · **急停（本地优先）**

| 字段 | 内容 |
|---|---|
| **描述** | 系统应提供急停能力，且急停**不依赖与设备的通信往返**：触发后立即进入急停态并切断危险动作。 |
| **验收判据** | ① 触发急停后**不等待通信确认**即转入急停态（界面 ≤ 1 个刷新周期内可见）<br>② 急停态下所有运动指令**被拒绝**并给出提示<br>③ 急停后必须**显式复位 + 使能**才可再次启动<br>④ **通信断开时急停仍然有效**（本地路径独立） |
| **前置条件** | 设备处于 就绪 / 运行 / 暂停 / 回零中 / 排胶中 任一状态 |
| **异常 / 边界** | 急停期间收到下发的程序 ⇒ **拒绝且不排队**；急停期间上位机崩溃 ⇒ 重启后**仍为急停态**（不得自行恢复为就绪） |
| **依赖** | `REQ-STA-002`（急停可从任意状态进入）· **`B5`**（虚拟下位机是否走通信 —— **决定"本地"的边界在哪**） |
| **来源** | `C1`（4/8）· S-1 附录 B 安全策略 · `P-5` |
| **优先级** | **P0**（安全） |
| **可测性** | **单测**（状态迁移）+ **演示**（断连下触发） |
| **状态** | ⏳ 待裁 |

## `REQ-RUN-005` · 复位 / 使能

| 字段 | 内容 |
|---|---|
| **描述** | 系统应提供复位操作，用于解除急停并恢复可运行状态；且复位后须"使能"才可启动。 |
| **验收判据** | ① 急停态下执行复位 ⇒ 急停标志**清除**<br>② 复位后**未使能**即下达启动 ⇒ **被拒绝**<br>③ 使能成功后状态转为**就绪** |
| **前置条件** | 设备状态 = 急停 |
| **异常 / 边界** | 复位**不等于回零**（两者语义不同，见 `REQ-RUN-006`）—— 复位只清状态，不动坐标 |
| **依赖** | `REQ-RUN-004` · `REQ-STA-003` |
| **来源** | `C1`（5/8）· `03-资料` 方向 1「急停恢复流程：复位→确认安全→使能」 |
| **优先级** | **P0**（安全） |
| **可测性** | **单测** + 演示 |
| **状态** | ⏳ 待裁 |

## `REQ-RUN-006` · 回零

| 字段 | 内容 |
|---|---|
| **描述** | 系统应能下达回零指令，使各轴回到机械基准位；未完成回零不得自动运行。 |
| **验收判据** | ① 下达回零 ⇒ 状态进入**回零中**，三轴依次归位<br>② 回零完成 ⇒ 坐标显示为基准值（如 `X=0, Y=0, Z=0`）<br>③ **未回零**即下达自动运行 ⇒ **被拒绝**并提示 |
| **前置条件** | 就绪 / 急停已复位 |
| **异常 / 边界** | 回零过程中下达急停 ⇒ 立即转入急停，**回零中断**且不得标记为"已回零" |
| **依赖** | `REQ-RUN-004` · `REQ-STA-001`（含"回零中"态）· **`B5`** |
| **来源** | `C1`（6/8）· `03-资料` 方向 1「开机必须回原点以保证坐标准确」 |
| **优先级** | **P0** |
| **可测性** | **单测** + 演示 |
| **状态** | ⏳ 待裁 |
