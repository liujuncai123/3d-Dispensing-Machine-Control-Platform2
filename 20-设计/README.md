---

## 使用规则

| # | 规则 |
|---|---|
| 1 | 一份工作稿对应**一层或一个切片**；不得出现"一个大文件装全部层"的情况 |
| 2 | 工作稿里产生的**待定项**，必须在 `../30-待裁决/` 同步挂一条，**不许只在稿里写"待定"**（依据上一轮教训：悬空的"待定"会永远挂着） |
| 3 | 工作稿通过冻结判据后，内容迁入 `../10-基线/`；**本处的文件降级为「指针」**（只写"权威源在哪"，**不保留内容副本**）—— 保留副本会造成两个权威源，违反 `../00-流程/02-文件结构规范.md` **C3** |
| 4 | 同一时刻**只允许存在一层的工作稿**（禁止 S0 未冻结就开 S1 稿） |
